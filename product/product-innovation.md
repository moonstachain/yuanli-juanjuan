# 叙世空间｜产品创新体系

版本：v1.1 · 2026-09-22 · 公开整理版

## 产品的四层价值

| 层次 | 用户想得到什么 | 对应交付 |
| --- | --- | --- |
| 个人表达 | 这很像我们，而不只是好看 | 理解访谈、故事主线、概念与视觉语言 |
| 关系体验 | 重要的人被看见并自然参与 | 邀请、抵达、等待、互动、离场的完整安排 |
| 筹备与现场安心 | 知道事情有人推进，知道如何确认 | 阶段计划、预算解释、打样与确认、变更记录 |
| 记忆与后续关系 | 重要经历能留下，未来仍可连接 | 经同意保存的故事、交付物及后续服务探索 |

前三层需要在真实项目中共同成立。第四层包含不同成熟度的方向，不能直接称为成熟复购或订阅业务。

## 从理解到表达

1. 用访谈与问卷了解经历、关系、期待及不希望发生的事情，允许客户只回答有答案的问题。
2. 确认客户想表达的价值与关系，写成双方能共同讨论的需求说明。
3. 设计仪式行为与宾客经历，再选择视觉、声音、材质和空间语言。
4. 通过建模、样品及情境说明缩小想象差异。
5. 让客户和执行团队分别确认表达与可实现性。
6. 项目后把真实反馈写回方法。

风格是表达的结果。互动与技术应当能解释它们服务哪一种情绪、关系或行动。

## 宾客体验设计

| 阶段 | 设计问题 |
| --- | --- |
| 被邀请 | 是否知道将进入怎样的世界，有怎样的参与期待 |
| 被迎接 | 是否容易找到位置，是否知道下一步 |
| 被辨认 | 是否感到自己与主人有真实关系 |
| 参与表达 | 是否能自然参与，是否可以自主选择 |
| 建立连接 | 是否有共同的情感入口 |
| 留下记忆 | 是否有值得带走或共同完成的内容 |

可以复用体验组织方式，同时保留每位客户的故事与选择。互动数量不能替代体验连贯性。

## 四个创新判断

- 表达真实：能从客户经历与需求解释关键设计。
- 来宾理解：有共同情感入口，也保留专属细节。
- 参与自然：不用靠复杂说明或强迫完成任务。
- 实现可靠：时间、预算、场地、供应商和备选方案能够支持。

## 长期记忆与品牌宇宙

可分别验证客户故事档案、可回访的故事体验、人生节点服务与特殊长期保存形式。先看客户是否愿意回来、持续留下内容及获得价值，再判断商业化方式。

保存故事与公开传播是两个不同用途，应分别确认。任何长期保存服务都需要明确实际能力、期限与持续责任。

## 对外内容表达

案例可以解释客户起初想表达什么、团队做过哪些关键判断、为什么舍弃某种方案，以及最终得到什么反馈。采用文字、图片或短内容进行低负担验证；发布频率与内容数量本身不能证明获客有效。
